5 Pilar Arsitektur Produksi

Didesain khusus untuk menangani trafik skala tinggi tanpa risiko ban dan kerusakan sesi.

🛡️

Persistensi Sesi Anti-Corrupt

Penulisan kunci enkripsi atomik dengan OS-level rename dan checksum SHA-256 integrity check. Dilengkapi auto-backup terenkripsi AES-256-GCM ke penyimpanan awan.

🚦

Antrean Pesan & Anti-Ban Jitter

Rate limiter dengan delay acak (jitter 1.5s–4.0s) yang meniru perilaku manusia, routing prioritas (High, Normal, Low), serta isolasi kegagalan dengan exponential backoff.

⚡

Streaming Media & Pembersihan TTL

Pemrosesan video/audio resolusi tinggi menggunakan stream.pipeline langsung ke disk tanpa membebani RAM heap, dengan worker pembersihan cache berkala.

🧩

Plugin Modular & Hot-Reloading

Command registry dinamis berbasis ESM/TypeScript yang dapat dimuat ulang (hot-reload) saat runtime tanpa me-restart koneksi socket WhatsApp.

📊

Observabilitas & Web Dashboard

Structured JSON logger dan HTTP monitoring server bawaan dengan endpoint /health, /metrics, dan antarmuka Web live QR Code scanner.

🔒

Native Signal & Noise Protocol

Implementasi protokol E2EE Noise XX dan Signal Protocol murni dengan manajemen PreKey bundle yang andal dan teruji fuzzer.

Quickstart Cepat

Menghubungkan bot WhatsApp hanya dengan beberapa baris kode TypeScript.

example-bot.ts
import { Wazeko, defaultClientConfig, AtomicFileAuthStore } from "wazeko";

// 1. Inisialisasi Auth Store Anti-Corrupt
const authStore = new AtomicFileAuthStore("./session", { checksumValidation: true });

// 2. Buat instance Wazeko Client
const client = new Wazeko(defaultClientConfig(), authStore);

// 3. Daftarkan Perintah (Hot-Reloadable)
client.plugins.register({
  name: "ping",
  execute: async (ctx) => {
    await ctx.reply("🏓 Pong! WhatsApp Bot Online.");
  }
});

// 4. Jalankan Web Monitoring & Hubungkan ke WhatsApp
await client.monitor.start();
await client.connect();
